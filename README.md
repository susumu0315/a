# resqmej 受注・発注管理

受注から発注書・納品書の作成、色別在庫までを、番号でつないで管理するアプリです。
社内で共有するときは **Google スプレッドシート** にデータを保存して使います（下の「社内で共有する（Google スプレッドシート版）」）。
`index.html` をブラウザで直接開くと、データをそのパソコンのブラウザに保存するお試し版として動きます。

## できること

| 機能 | 内容 |
| --- | --- |
| ① 受注登録 | お客様からの注文を登録します。**自社受注No.**（自動採番）・**お客様の発注No.**・担当者・希望納期・回答納期・請求書の状況を記録します。 |
| ② 発注書 | 受注から仕入先あての発注書を作成します。受注の明細が取り込まれ、**発注No.**が自動で採番されます。 |
| ③ 納品書 | 受注から納品書を作成します。**まだ納品していない数量**が自動で入るので、分納にも対応できます。在庫が足りないときは保存前に知らせます。 |
| 在庫（色別） | 現在庫＝期首在庫＋入庫累計−出荷済（納品書）、有効在庫＝現在庫−引当（未納品の受注）を自動で計算し、発注点を下回った色を「要発注」と表示します。入庫もここで登録します。 |
| 見込み案件 | 注文前の案件を記録し、決まったら「受注にする」で受注登録へ引き継げます。 |
| 請求書・領収書 | 納品書の画面の「請求書・領収書も表示」で、**納品書・請求書・領収書を 1 画面にまとめて**表示し、まとめて PDF にできます（1 書類 1 ページ。印刷する書類は選べます）。請求書には振込先・お支払期限・税率ごとの金額、領収書には但し書き・収入印紙欄（税抜 5 万円以上）が入ります。 |
| 納期の警告 | 納期が近い（初期設定は 3 日以内）または過ぎている未納品の受注と、その発注書を、全画面の上部に赤い帯で表示します。起動時には 1 日 1 回ポップアップでも知らせます。日数は設定画面で変えられます。 |
| 請求書の状況 | 受注ごとに 未処理 → 発行済 → 送付済 → 入金確認済 を管理します。ホームに「納品完了で請求書が未処理」の件数を表示します。 |
| 紐付け表示 | 受注 → 発注書 → 納品書 のつながりを 1 画面で確認でき、各カードから書類へ移動できます。 |
| 番号検索 | 自社受注No.・お客様発注No.・発注No.・納品書No.・会社名のどれで検索しても、関連する書類がまとめて表示されます。 |
| PDF 印刷 | 発注書・納品書を A4 の帳票として印刷、または PDF で保存できます。 |
| 取引先の紐付け | 取引先ごとに受注・発注書・納品書を一覧で確認でき、そこから受注・発注書を作成できます。取引先の住所などを変えると、作成済みの書類にも反映されます。 |
| マスタ | 品名・色・担当者をプルダウンで選べます。「商品・色・担当」画面でいつでも追加できます。 |
| 社内共有 | Google スプレッドシート版では、全員が同じデータを見ます。他の人の変更は 1 分ごと（または画面に戻ったとき）に反映されます。同じデータを同時に変更したときや、番号が重なったときは、後から保存した人に知らせて最新の内容を読み込み直します。 |

## 番号の紐付け

```
お客様の発注No. ─┐
                 ├─ 自社受注No.（JO-2026-0001）
                 │     ├─ 発注書 PO-2026-0001（仕入先あて。当社受注No.を印字）
                 │     └─ 納品書 DN-2026-0001（お客様あて。貴社発注No.・当社受注No.を印字）
```

- 番号は「頭文字-西暦-連番」の形で自動採番されます。頭文字は「設定」画面で変更できます。
- 自動で付いた番号は入力画面で書き換えることもできます。ただし同じ番号は二重に登録できません。

## 社内で共有する（Google スプレッドシート版）

データは会社の Google アカウントで作ったスプレッドシートに保存され、アプリはそのスプレッドシートに付いた Apps Script から配信されます。
最初に 1 回だけ、管理する人が次の設定を行います（15 分ほど）。

1. Google ドライブで新しいスプレッドシートを作り、名前を付けます（例：`resqmej 受注・発注データ`）。
2. スプレッドシートのメニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このリポジトリの [`gas/Code.gs`](gas/Code.gs) の内容を貼り付けます。
4. 左の「ファイル」の **＋ → HTML** で、名前を `Index` にしたファイルを作り、中身を [`gas/Index.html`](gas/Index.html) の内容に置き換えます。
5. 💾 保存してから、右上の **デプロイ → 新しいデプロイ** を開き、種類（⚙）で **ウェブアプリ** を選びます。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**（会社のドメイン）内の全員**（Google Workspace でない場合は「Google アカウントを持つ全員」）
6. 「デプロイ」を押し、表示される許可の画面で承認します。表示された **ウェブアプリの URL** を社内に共有してください。
   この URL を開くと、最初の 1 回だけ取引先・色などの初期データがスプレッドシートに書き込まれます。

**Excel（防災品_受注管理表）の取り込み**：パソコンで
`python tools/import_excel.py 防災品_受注管理表.xlsx 取込データ.json` を実行し、できた JSON をアプリの
**設定 → バックアップから復元** で読み込みます（スプレッドシートの内容がすべて置き換わるので、運用を始める前に 1 回だけ行ってください）。

**アプリを更新したとき**：`node tools/build-gas.js` で `gas/Index.html` を作り直し、Apps Script の `Index` と `Code.gs` を貼り替えてから、
**デプロイ → デプロイを管理 → ✎ 編集 → バージョン：新バージョン → デプロイ** を押します（URL は変わりません）。

**注意**
- スプレッドシートの各シート（受注・納品書・在庫など）は保存先です。`data` 列を直接書き換えないでください。`内容` 列で中身を確認できます。
- スプレッドシートの変更履歴（ファイル → 変更履歴）から過去の状態に戻すこともできます。念のため、設定画面の「バックアップを保存」も定期的に行ってください。

## 使い方

1. **設定**：自社情報（ミカド電子株式会社 防災事業部）は最初から登録済みです。**インボイス登録番号・振込先**を登録してください（請求書・領収書に印字されます）。FAX・担当者名なども必要なら追加してください。会社ロゴも帳票に印字されます。
2. **受注を登録**：「＋ 新しい受注を登録」から入力します。取引先は入力画面の「＋ 新規」からその場で登録できます。
3. **発注書を作る**：仕入先へ発注する場合は、受注の詳細画面で「＋ この受注の発注書を作る」を押し、仕入単価を入力して保存します。
4. **納品書を作る**：受注の詳細画面で「＋ この受注の納品書を作る」を押します。残りの数量が自動で入ります。保存すると在庫の「出荷済」に入ります。
5. **PDF で印刷・保存**：書類の画面で「🖨 PDFで印刷・保存」を押し、印刷画面の送信先で「PDF に保存」を選びます。
   - 「ヘッダーとフッター」のチェックを外すと、余計な URL や日付が印字されません。
6. **在庫**：入荷したら「在庫」画面で入庫を登録します。期首在庫と発注点は同じ画面で変更できます。

## ファイル構成

```
index.html             画面の骨組み
css/style.css          画面と帳票（印刷）のデザイン
js/app.js              アプリ本体（データ管理・画面・帳票）
img/logo.png           帳票に印字する会社ロゴ
gas/Code.gs            Google スプレッドシートに保存するサーバー側の処理（Apps Script）
gas/Index.html         Apps Script 用に 1 ファイルにまとめた画面（tools/build-gas.js で生成）
tools/build-gas.js     gas/Index.html を作るスクリプト
tools/import_excel.py  防災品_受注管理表.xlsx をバックアップ形式に変換するスクリプト
```
