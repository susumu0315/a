# resqmej 受注・発注管理

受注から発注書・納品書の作成までを、番号でつないで管理するアプリです。
インストールは不要で、`index.html` をブラウザ（Chrome / Edge 推奨）で開けばすぐに使えます。

## できること

| 機能 | 内容 |
| --- | --- |
| ① 受注登録 | お客様からの注文を登録します。**自社受注No.**（自動採番）と**お客様の発注No.**を記録します。 |
| ② 発注書 | 受注から仕入先あての発注書を作成します。受注の明細が取り込まれ、**発注No.**が自動で採番されます。 |
| ③ 納品書 | 受注から納品書を作成します。**まだ納品していない数量**が自動で入るので、分納にも対応できます。 |
| 紐付け表示 | 受注 → 発注書 → 納品書 のつながりを 1 画面で確認でき、各カードから書類へ移動できます。 |
| 番号検索 | 自社受注No.・お客様発注No.・発注No.・納品書No.・会社名のどれで検索しても、関連する書類がまとめて表示されます。 |
| PDF 印刷 | 発注書・納品書を A4 の帳票として印刷、または PDF で保存できます。 |
| 取引先の紐付け | 取引先ごとに受注・発注書・納品書を一覧で確認でき、そこから受注・発注書を作成できます。取引先の住所などを変えると、作成済みの書類にも反映されます。 |
| 商品・色マスタ | 品名（レスキューミー）と色をプルダウンで選べます。色や商品は「商品・色」画面でいつでも追加できます。 |
| 状況管理 | 未発注 → 発注済・納品待ち → 一部納品 → 納品完了 を自動で判定します。ホーム画面には納期が近い受注を表示します。 |
| バックアップ | データを JSON で保存・復元できます。紐付け一覧は Excel で開ける CSV で出力できます。 |

## 番号の紐付け

```
お客様の発注No. ─┐
                 ├─ 自社受注No.（JO-2026-0001）
                 │     ├─ 発注書 PO-2026-0001（仕入先あて。当社受注No.を印字）
                 │     └─ 納品書 DN-2026-0001（お客様あて。貴社発注No.・当社受注No.を印字）
```

- 番号は「頭文字-西暦-連番」の形で自動採番されます。頭文字は「設定」画面で変更できます。
- 自動で付いた番号は入力画面で書き換えることもできます。ただし同じ番号は二重に登録できません。

## 使い方

1. **設定**：自社情報（ミカド電子株式会社 防災事業部）は最初から登録済みです。インボイス登録番号・FAX・担当者名などが必要なら追加してください。会社ロゴ（`img/logo.png`）も帳票に印字されます。
   取引先（株式会社ボウエキ・防災品受注管理表の取引先 計 8 社）も登録済みです。住所や電話番号は「取引先」画面の「編集」から追加してください。
2. **受注を登録**：「＋ 新しい受注を登録」から入力します。取引先は入力画面の「＋ 新規」からその場で登録できます。
3. **発注書を作る**：受注の詳細画面で「＋ この受注の発注書を作る」を押し、仕入単価を入力して保存します。
4. **納品書を作る**：受注の詳細画面で「＋ この受注の納品書を作る」を押します。残りの数量が自動で入ります。
5. **PDF で印刷・保存**：書類の画面で「🖨 PDFで印刷・保存」を押し、印刷画面の送信先で「PDF に保存」を選びます。
   - 「ヘッダーとフッター」のチェックを外すと、余計な URL や日付が印字されません。

まずは動きを見たいときは、ホーム画面の「サンプルデータで試してみる」を押してください。

## データの保存について

- データは**使っているパソコンのブラウザの中**（localStorage）に保存されます。サーバーには送信されません。
- 別のパソコンやブラウザとはデータが共有されません。移すときは「設定 → バックアップを保存」で作ったファイルを、移した先で「バックアップから復元」してください。
- ブラウザの閲覧履歴やサイトデータを消すと、保存したデータも消えます。**定期的にバックアップを保存してください。**

## ファイル構成

```
index.html      画面の骨組み
css/style.css   画面と帳票（印刷）のデザイン
js/app.js       アプリ本体（データ管理・画面・帳票）
img/logo.png    帳票に印字する会社ロゴ
```

## GitHub Pages で公開する場合

リポジトリの Settings → Pages で `main` ブランチのルートを指定すると、URL を開くだけで使えるようになります。
データは、開いた人それぞれのブラウザに保存されます。
